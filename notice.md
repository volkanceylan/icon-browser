# Icon set notices

Icons are provided by the [Iconify](https://iconify.design/) icon sets and
remain the property of their respective authors. This browser displays them
locally; the copied CSS embeds the icon geometry as a data URI.

The class prefix is what the icon set prefix maps to in the copied
`.sv-<prefix>-<name>` rules. Multicolor (palette) icons use
`.svbg-<prefix>-<name>` instead (background mode, keeping their colors).

## Iconify

- Project: Iconify — <https://iconify.design/>
- License: MIT (the Iconify API, tooling and JSON format) —
  <https://github.com/iconify/iconify> and <https://github.com/iconify/api>
- Data source: <https://icon-sets.iconify.design/>
- The icon data comes from the `@iconify-json/*` packages; each icon set keeps
  its own license and author, listed below.
